# 整合验证记录

验证平台：Ubuntu / ROS2 Humble，x86_64，系统 Python 3.10；不连接机器狗、不启动雷达驱动。

## 已验证

- 内置 C++ 后端从源码重新编译成功；源码 SHA256 核对通过。
- 8 项行为测试通过：带行填充的大端 PointCloud2、无效点、双 IMU 静止交集/缺流、配准方向、单平面退化拒绝、初值/配置检查、PCD/位姿往返、同位置跨集合泄漏拒绝、验证失败不导出部署文件（部分在同一测试中）。
- 已知矩阵的静止多位姿数据完成三阶段优化和两组扰动初值复算；旋转误差约 0.00185°，平移误差约 0.000088 m。
- 标准 ROS2 sqlite3 合成录包完成普通用户流程：自动提取 8 个静止片段、前点云估计位姿、MLCC、验证及导出；旋转误差约 0.00155°，平移误差约 0.000058 m。
- 使用另一个采样数据集复核固定候选通过；重复原标定数据的“独立复核”会拒绝。
- 交互式生成配置、已有配置不覆盖、已有结果目录不覆盖均通过。
- 导出 YAML 可由现有 C++ 融合程序直接读取。

上述合成误差仅验证软件链路和坐标方向，不代表实机精度。

## 真实历史数据回归

将已有 packet 实验中经过运动检查的 10 对扫描、前雷达独立位姿及原安装初值，按新 dataset 输入契约导入。保留每个位置最多两帧，按 3 个训练位置、2 个留出位置划分。

- 新工具的最终矩阵与原三阶段求解结果差约 6.7e-11° / 1.2e-11 m，说明整合保持了该输入上的求解结果。
- 这些稀疏扫描在新工具的前点云参考和统一门限下，共同平面覆盖不足，标定后合并残差 RMSE 约 0.089 m；工具返回 2，仅保留候选和报告，不生成 `extrinsics.yaml`。
- 未调整门限以强行通过该历史样本。原实验另有局部稠密地图验证，使用的参考和数据范围不同，不能与此处指标直接等同。

## 重复软件验证

在本目录执行：

```bash
/usr/bin/python3 -m unittest discover -s tests -p 'test_*.py' -v
source /opt/ros/humble/setup.bash
/usr/bin/python3 tests/check_integration.py
```

集成测试会在 `/tmp/` 新建独立目录，生成测试 bag 和结果，不读取历史实验、不改在线配置、不启动 ROS 节点。

## 尚需实机确认

尚未使用本整合工具在另一台真实机器狗上完成全流程采集和独立复核，也未做 ARM64 性能验证。新安装仍需粗略安装初值、合适的静态场景、足够的不同位姿以及独立录包/实际尺寸检查。自动几何检查和多初值稳定性不等于真值精度验收。
