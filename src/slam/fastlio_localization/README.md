## Build and run
### 1. Prerequisites
#### 1.1 **Ubuntu** and **ROS 2**

Use the ROS 2 version configured by this workspace.

#### 1.2. **PCL && Eigen**
PCL    >= 1.8,   Follow [PCL Installation](http://www.pointclouds.org/downloads/linux.html).

Eigen  >= 3.3.4, Follow [Eigen Installation](http://eigen.tuxfamily.org/index.php?title=Main_Page).

#### 1.3. **livox_ros_driver2**

The ROS 2 build depends on `livox_ros_driver2`.

### ROS 2 RoboSense Airy offline localization

`config/reloc_airy96.yaml` subscribes to `/rslidar_points` and
`/rslidar_imu_data`. Its `lidar_type: 5` selects the Airy `PointCloud2` input
(`x/y/z/intensity`: float32, `ring`: uint16, `timestamp`: float64 seconds).
The same node performs initial BBS3D relocalization and then continuous
LiDAR-IMU localization.

The map directory must contain the matching `globalmap.pcd` and the BBS3D
`voxelmaps_coords` generated by the map loading workflow. Use a robot parameter
file with the recording sensor's `lidar_to_base_T/R`; the default shared file
contains the P2 robot calibration.

```bash
ros2 launch fastlio_localization run_launch.py \
  config_file:=reloc_airy96.yaml \
  map_path:=/path/to/map \
  robot_param_file:=/path/to/p3_airy96.yaml
ros2 bag play /path/to/airy96_fastlio_20250604_222402 --rate 0.5
```

Check `/reloc_success` for successful relocalization and
`/pose_stamped_localization` for the continuing pose output. The Airy
`extrinsic_T/R` in the profile came from the mapping profile and must match
the sensor that recorded the bag.
